# Журнал реализации

## Назначение

Этот файл фиксирует ход разработки интерактивной визуализации курсовой
работы по ОТС. Проект реализуется последовательно, по одному смысловому
блоку тракта за раз.

Перед началом реализации каждого блока обязательно проводится отдельное
исследование методических указаний `docs/coursework_methodical_instructions.docx`.
Нельзя добавлять расчёт или формулу только на основании общего понимания
темы: сначала нужно найти соответствующий раздел методички и зафиксировать
основание для реализации в этом журнале.

## Обязательный процесс работы над блоком

Для каждого блока нужно пройти все этапы:

1. Найти относящиеся к блоку разделы методических указаний.
2. Выписать, что физически происходит с сигналом.
3. Зафиксировать входной и выходной сигналы.
4. Перепроверить формулы по визуальному представлению в Word, если текстовое
   извлечение потеряло дроби, индексы или специальные символы.
5. Выбрать обязательный основной график преобразования сигнала.
6. Определить дополнительные поясняющие графики, если без них причина
   преобразования неочевидна.
7. Реализовать расчёт, описание и визуализацию.
8. Проверить численный результат и поведение интерфейса.
9. Записать итог и ограничения в этот журнал.

## Критерии готовности одного блока

Блок можно считать завершённым, только если:

- указаны использованные разделы методички;
- описан физический смысл преобразования;
- зафиксированы формулы и исходные параметры;
- присутствует минимум один график изменения сигнала;
- дополнительные графики добавлены там, где они помогают объяснению;
- графики обновляются при изменении доступных параметров;
- интерфейс показывает входной и выходной сигналы;
- выполнена ручная проверка страницы в браузере;
- журнал обновлён.

### 2026-06-01 — Исходные данные варианта

**Разделы методички:** раздел `2.2 Исходные данные`, страницы с таблицей 1
«Исходные данные для расчётов (индивидуальные задания)».

**Что происходит с сигналом:** блок задаёт начальные условия для всех
последующих расчётов. Сам сигнал на этом этапе ещё не преобразуется.
Непрерывное сообщение `c(t)` далее рассматривается как реализация
стационарного гауссовского случайного процесса с нулевым средним значением
и известной корреляционной функцией `B_c(τ)`.

**Вход:** значения индивидуального задания пользователя.

**Выход:** единое состояние приложения с параметрами `P_g = σ_g²`, `β`,
`Δf_g`, `α`, способом передачи, частотами несущей, `N₀`, `h²`, способом
приёма, `δ²доп` и корреляционной функцией `B_c(τ)`.

**Формулы:** расчётов на этом этапе нет. Из раздела 2.2 зафиксированы связи
для следующих блоков: частота дискретизации `f_д = 2αf_g`; для ДАМ и ДОФМ
задаётся частота `f₀`, для ДЧМ — частоты `f₁` и `f₂`.

**Основной график:** не требуется, потому что блок конфигурационный и не
изменяет сигнал. Первый график преобразования появится в блоке «Источник и
первичный преобразователь».

**Дополнительные графики:** не требуются.

**Реализация:** добавлена форма ручного ввода и живая сводка параметров.
При выборе ДЧМ форма показывает две частоты. При выборе ДАМ или ДОФМ
остаётся одна несущая частота `f₀`. Доступные способы приёма автоматически
меняются: `КО / НО` для ДАМ и ДЧМ, `СФ / СП` для ДОФМ.

После получения скриншотов таблицы 1 добавлен выбор готового варианта
`1–40`. При выборе номера все поля заполняются автоматически, включая
корреляционную функцию `B_c(τ)` и ширину спектра `Δf_g`. Если пользователь
после этого изменяет любое поле, форма возвращается в режим ручного ввода.

Уточнена зависимость ширины спектра первичного сигнала от функции
корреляции. Для каждой группы вариантов из таблицы 1 зафиксировано
соотношение `Δf_g = kβ`, где `k` принимает значения `1`, `1,5`, `2`, `3`
или `4`. В форме пользователь задаёт `β` и коэффициент `k`, а значение
`Δf_g` рассчитывается автоматически. В сводке дополнительно показывается
сама подстановка.

У выбора способа приёма добавлены динамические пояснения. Для `КО` и `НО`
показывается различие между синхронной обработкой с опорным колебанием и
выделением огибающей без знания текущей фазы. Для `ДОФМ` поясняются методы
сравнения фаз (`СФ`) и сравнения полярностей (`СП`).

Формулы переведены на хранение в формате LaTeX и отображение через MathJax.
Для корреляционной функции добавлен живой предпросмотр рядом с ручным
редактором. В сводке `B_c(τ)` и зависимость `Δf_g = kβ` показываются как
отдельные математические блоки. Этот механизм будет повторно использоваться
для формул следующих этапов.

**Ограничения и решения:** корреляционные функции в таблице 1 хранятся
внутри Word как формульные объекты и теряются при обычном текстовом
извлечении. Для блока исходных данных они перенесены со скриншотов таблицы.
Перед построением графиков в блоке источника формулы будут отдельно
перепроверены по исходному изображению.
